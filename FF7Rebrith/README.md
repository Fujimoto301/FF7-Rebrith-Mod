## บันทึกเริ่มต้น Chapter 1 (ขอบเขตและสถานะในอดีต)

งานปัจจุบันจำกัดเฉพาะ **Chapter 1** ตามคำขอผู้ใช้ คำแปลเขียนครบ 1,157 รายการจากข้อความญี่ปุ่น ครอบคลุมฉากเปิด เหตุการณ์ย้อนอดีต บทคุยชาวบ้าน และบทพูดบอสที่มีรหัสเฉพาะบทนี้ **ยังไม่ได้ทดสอบขณะเล่นเกม**

ไฟล์สำหรับทดลอง: `dist/ThaiJP_Chapter1_P.zip` คู่มือติดตั้งปัจจุบัน: `README-MENU-TRIAL.md`

งานเมนูเพิ่มเติมคือคำแปลหน้าเริ่มเกม เมนูหลัก เมนูหยุดเกม เซฟ/โหลด และเฉพาะข้อความญี่ปุ่นในหน้าเลือกระดับความยาก/โหมดต่อสู้ เปลี่ยนข้อความ 533 รายการ เก็บแยกใน `translations/menu-th.json` และไฟล์ทำงานรวม `translations/working-th.json` ตามคำสั่งล่าสุดได้รวมเข้ากับ ZIP ทดลอง Chapter 1 และติดตั้งใน `~mods` แล้ว โดยสำรองรุ่นเก่าและตรวจค่าแฮชหลังติดตั้ง รายละเอียดดู `MENU-STATUS.md` งานเพิ่มเติมถัดไปยังเก็บเป็นไฟล์ทำงานก่อนจนกว่าจะมีคำสั่งให้แพ็กหรือติดตั้ง

## ข้อกำหนดที่ใช้

- ชื่อผู้พูดและชื่อในเมนูเป็นภาษาอังกฤษ เช่น Cloud, Tifa, Sephiroth ตามชื่อทางการในไฟล์ภาษาอังกฤษของเกม
- ชื่อที่กล่าวในประโยคบทพูดถอดเป็นไทย เช่น คลาวด์ ทีฟ่า เซฟิรอธ
- ใช้บริบทและคำศัพท์จากม็อด Remake ของ PlearnGaming ที่ผู้ใช้ให้มา มีหลักฐานตำแหน่งข้อความใน `reference/plearngaming/glossary.json`
- ฟอนต์ไทยใช้ Noto Sans Thai น้ำหนัก 300 เทียบเส้นและรูปทรงกับฟอนต์จริงของเกม ส่วนอักษรอังกฤษใช้ glyph เดิมของเกม
- แก้ช่องข้อความญี่ปุ่น จึงต้องเลือกข้อความ Japanese และเสียง Japanese หน้าเริ่มเกม เมนูหลัก เมนูหยุด และเซฟ/โหลดเป็นไทยแล้ว ส่วนค่าตั้งค่าและคำอธิบายรายละเอียดภายใน OPTIONS ยังเป็นต้นฉบับ
- ข้อความของ Chapter 2 เป็นต้นไปคงเดิม ไม่รวมการแปลเมนูทั้งหมด คำสอนระบบ หรือบทพูดต่อสู้ที่ใช้ร่วมกันหลายบท

## ไฟล์ทำงาน

- `translations/chapter1/batch-*.json` — คำแปลไทยที่แก้ไขได้ ใช้ index จาก source ที่บันทึกไว้
- `translations/chapter1-th.json` — คำแปลที่รวมพร้อมรหัสข้อความและป้ายชื่ออังกฤษ
- `reference/chapter1-source.json` — ต้นฉบับญี่ปุ่น 1,157 รายการพร้อมรหัสและ metadata
- `reference/chapter1-actor-labels.json` — คู่ชื่อญี่ปุ่น/อังกฤษจากข้อความเกม
- `reference/plearngaming/glossary.json` — คำศัพท์จากม็อดอ้างอิงพร้อมหลักฐาน
- `qa/chapter1/verification.json` — ตรวจขอบเขตข้อความ ป้ายชื่อ glyph เดิม และ texture ผ่านตัวอ่าน UE4 แยกต่างหาก
- `qa/chapter1/package-verification.json` — อ่านแพ็กกลับเทียบทุก asset กับ staging
- `qa/chapter1/subtitle-preview.png` — ภาพตรวจฟอนต์จาก asset ที่สร้าง เป็นภาพจำลอง ไม่ใช่ภาพในเกม

ข้อความอ้างอิง Remake ถอดรหัสได้แล้วโดยยังมีอักขระหายากบางตัวต้องตรวจบริบท ส่วน Crisis Core แตก Atel ได้ 776 ไฟล์ แต่ยังไม่ยืนยันการถอดข้อความ จึงใช้ Remake เป็นฐานคำศัพท์ที่อ่านและตรวจได้ในตอนนี้
