# แพ็กทดลอง Chapter 1 และเมนูไทย

คำแปลบทพูด Chapter 1 จำนวน 1,157 รายการ พร้อมหน้าเริ่มเกม เมนูหลัก เมนูหยุดเกม เซฟ/โหลด และข้อความญี่ปุ่นในหน้าเลือกระดับความยาก/โหมดต่อสู้ รวมข้อความเมนูที่เปลี่ยน 533 รายการ ชื่อตัวละครใน UI เป็นอังกฤษ ชื่อไอเทมและสกิลที่กล่าวถึงในคำแนะนำคงอังกฤษ ข้อมูลชื่อและความสามารถไอเทม/สกิลในฐานข้อมูลยังไม่เริ่มแปล

OPTIONS แปลชื่อหมวด คำอธิบายหมวด และข้อความญี่ปุ่นในหน้าเลือกระดับความยาก/โหมดต่อสู้ คง EASY, NORMAL, ADVANCED, HARD, ACTION และ CLASSIC เป็นอังกฤษ ค่าตั้งค่าและรายละเอียดหน้าอื่นยังเป็นต้นฉบับ ฟอนต์ไทย Noto Sans Thai Light ใช้ร่วมกับ glyph เดิมของเกม ปรับแนวเลข 0–9 และอักษรอังกฤษในบรรทัดที่ผสมไทย โดยไม่เปลี่ยน glyph ASCII เดิมหรือชื่อผู้พูด

แพ็กใช้ชื่อเดิมเพื่ออัปเดตทับรุ่นทดลองก่อนหน้า:

- `ThaiJP_Chapter1_P.pak`
- `ThaiJP_Chapter1_P.utoc`
- `ThaiJP_Chapter1_P.ucas`

ปิดเกมก่อนคัดลอกทั้ง 3 ไฟล์ไปที่ `E:\steam\steamapps\common\FINAL FANTASY VII REBIRTH\End\Content\Paks\~mods` จากนั้นเปิดเกมใหม่ ตั้ง Text & Subtitles และ Voice-over เป็น Japanese ไม่ติดตั้งแพ็กต้นแบบหรือม็อดที่แก้ font/text เดียวกันซ้อนกัน

ZIP แตกออกมาเป็นม็อด 3 ไฟล์เท่านั้น ข้อความใบอนุญาตและลิขสิทธิ์ฟอนต์ฉบับเต็มเก็บใน Comment ของ ZIP เพื่อเปิดอ่านได้ด้วยโปรแกรมที่รองรับ archive comments เก็บ ZIP เดิมไว้พร้อมข้อมูลนี้เมื่อนำไปส่งต่อ คู่มือ ผลตรวจ และค่าตรวจสอบไฟล์เก็บแยกในโฟลเดอร์งาน

ตรวจข้อความ แท็ก ตัวแปร metadata ข้อความนอกขอบเขต glyph เดิม และภาพฟอนต์ทั้ง 8 ขนาดแล้ว แพ็กต้องอ่านกลับเทียบไฟล์ทำงานครบ 20 assets ก่อนติดตั้ง การตรวจไฟล์ยังไม่ยืนยันผลขณะเล่นเกม โดยเฉพาะความกว้างปุ่มและกล่องข้อความเมนู
