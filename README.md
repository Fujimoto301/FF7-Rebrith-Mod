# FF7 Rebirth Thai Translation Mod

ม็อดคำแปลภาษาไทยสำหรับ Final Fantasy VII Rebirth ครอบคลุม Ch.1–14 และ Common

## ดาวน์โหลด

ดาวน์โหลด [ThaiJP_AllChapters_P.zip](Mod/Final/ThaiJP_AllChapters_P.zip) จากโฟลเดอร์ `Mod/Final` ใน repo นี้ แล้วแตกไฟล์ ZIP ก่อนติดตั้ง

## วิธีติดตั้ง

1. ปิดเกมก่อน
2. เปิดโฟลเดอร์ติดตั้งเกม แล้วเข้า `End/Content/Paks` ตัวอย่างตำแหน่งบน Steam คือ `steamapps/common/FINAL FANTASY VII REBIRTH/End/Content/Paks`
3. สร้างโฟลเดอร์ `~mods` ภายใน `Paks` หากยังไม่มี
4. คัดลอกไฟล์ `.pak`, `.utoc` และ `.ucas` จาก ZIP ไปไว้ใน `Paks/~mods`
5. เปิดเกมและตั้งค่า `Text & Subtitles` เป็น Japanese เพื่อใช้ข้อความที่ม็อดแก้ไข

## ถอนการติดตั้ง

ปิดเกม แล้วลบไฟล์ `ThaiJP_AllChapters_P.pak`, `ThaiJP_AllChapters_P.utoc` และ `ThaiJP_AllChapters_P.ucas` ออกจาก `Paks/~mods`

## หมายเหตุ

- ใช้ ZIP รวมล่าสุดเพียงไฟล์เดียวจาก `Mod/Final`
- ม็อดแก้ข้อความในชุดภาษาญี่ปุ่นของเกม จึงต้องเลือก `Text & Subtitles` เป็น Japanese
- การติดตั้งและถอนการติดตั้งทำด้วยการคัดลอกหรือลบไฟล์ตามขั้นตอนด้านบน
